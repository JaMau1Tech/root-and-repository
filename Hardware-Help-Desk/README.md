## Ticket Numbering Convention

`HWD-YYYY-###`
- `HWD` = Hardware / Help-Desk category
- `YYYY` = year the ticket was opened
- `###` = zero-padded sequential number, resetting each year (e.g., `HWD-2026-001`, `HWD-2026-002`, ...)
