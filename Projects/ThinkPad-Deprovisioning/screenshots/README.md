# Screenshots

This folder contains screenshots documenting the ThinkPad Deprovisioning & Recovery project.

Screenshots are organized by phase: the Windows/Autopilot investigation, the Linux Mint install, and post-install diagnostics.

---

# Purpose

Screenshots provide visual evidence of:

- What was attempted
- What errors or prompts appeared
- What settings were changed
- What the diagnostic output showed
- What the final working state looks like

---

# Naming Convention

Use lowercase filenames with hyphens.

Good examples:

```text
thinkpad-deprov-autopilot-oobe-screen.png
thinkpad-deprov-bios-secureboot-config.png
thinkpad-deprov-mint-installer-disk-selection.png
thinkpad-deprov-mint-post-install-desktop.png
thinkpad-deprov-ufw-status-output.png
thinkpad-deprov-upower-battery-report.png
thinkpad-deprov-sensors-output.png
thinkpad-deprov-wifi-driver-check.png
```

Avoid:

```text
Screenshot 2026-09-18.png
IMG_1234.png
Untitled.png
```

---

# Lessons Learned

- Clear screenshot names prevent confusion when a project spans multiple troubleshooting phases.
- Terminal output screenshots double as evidence and as a readable record of the exact commands run.
