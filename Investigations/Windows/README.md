# Windows Investigations

## Overview

This directory contains hands-on Windows investigations performed using native Windows command-line tools, as well as real-world incident response and system recovery work. Each investigation focuses on developing practical system administration, troubleshooting, and incident response skills.

| Investigation | Focus | Status |
|---------------|-------|--------|

| Investigation 02 - Process Analysis | Running process enumeration using Tasklist | ✅ |
| Investigation 03 - Network Connections | Active connections, TCP states, listening ports, and PID correlation | ✅ |
| Investigation 04 - Malware Incident & System Recovery | Real-world malware detection, full system reinstall, and post-incident hardening | ✅ |
