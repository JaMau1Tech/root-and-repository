# CompTIA A+ Core 1 (220-1201)

Documentation for coursework toward the CompTIA A+ Core 1 exam, built to `Standards/Certification-Coursework-Standard.md`. Each completed module produces three files: Study Notes, Objectives, and Practice Questions (plus `.docx` printable copies of Study Notes/Objectives).

Course source: instructor-provided coursework (Schoology, CPT SYSTEMS TECH) cross-referenced against CertMaster and CompTIA's own official 220-1201 objectives.
